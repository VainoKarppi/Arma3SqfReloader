# Arma example templates

These are the editable source files used by **SqfReloader: Create example mod**:

- `client-example/` contains the `@ExampleMod` client example, the `.vscode` project-settings
  template, and optional `missions/example.Altis` and `mpmissions/example.Altis` templates. The
  mission folders are copied when mission creation is enabled in the project settings.
- `server-example/` is copied to `server-example/` in the opened workspace.

Edit these files to change what the command creates. Once generated, project settings belong to
the workspace user and are not overwritten, even when recreating the example.
